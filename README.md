## 三、固件文件格式与命名规则

| 后缀 / 标识 | 含义 |
|---|---|
| `.bin.web` | **加密**升级包（MTK 机型主用），需解密后方可解包研究 |
| `.bin.online` | **加密**升级包（RE 系列等机型） |
| `.bin` | 解密后的可刷固件 |
| `.iso` / `.img` / `.GHO` | x86 安装镜像 / 写盘镜像（**同一固件内容等价**，按需选用） |
| `.rar` / `.zip` | 官方分发的压缩包（底包、二合一安装包等） |
| `.ini` | 厂商发布清单（含最新版本号 / 日期 / MD5 / 更新日志） |
| `GOCLOUD-` | 官方主品牌前缀 |
| `TG-NET-` / `UTT-` / `TE-NET-` | **OEM 贴牌**前缀（同一固件、不同品牌分发） |
| `WWWS-` | 文网卫士（高恪定制版）前缀 |
| `GC-` | 无线 AP 系列前缀 |

> ⚠️ **刷机对应关系**：x86 机型（SX / ISP 系列）用 `.iso` / `.img` 装机；
> MTK 机型（S1A / S2A / S3A 等）用 `.bin.web` 升级包；
> **跨大版本、或从第三方固件切换时，建议先刷「底包」再刷目标版本**。

## 五、存放方式（GitHub Releases）

固件本体以 **Release 资产**形式存放（不占用仓库体积），按**版本目录**打包为 **zip（store 不压缩）**。

| Release | 内容 | 资产数 | 体积 |
|---|---|---|---|
| `stable` | 稳定版固件 | 140 | 6.49 GB |
| `beta` | 公测版固件 | 164 | 12.14 GB |
| `base` | 底包 / 安装镜像 | 22 | 1.52 GB |
| `wifi-ap` | 无线 AP 固件（AH / GC 系列） | 7 | 0.65 GB |
| `ap` | AP 板卡固件 | 9 | 0.17 GB |
| `manifests` | 厂商 `.ini` 清单 | 13 | 约 100 KB |
| `misc` | 文档 PDF + 工具 + `MANIFEST.csv` | 6 | 约 10 MB |
| **合计** | | **361** | **20.99 GB** |

**命名规则**（GitHub 会剥离资产名中的非 ASCII 字符，实测 `高恪路由器配置指南2021版.pdf` → `2021.pdf`）

| 项 | 规则 | 示例 |
|---|---|---|
| 资产名 | ASCII 骨架 `<tag>__<版本>.zip` | `stable__5.2.2__5.2.2.22550.zip` |
| | misc 文档/工具：`<前缀>_<骨架>_<6位哈希>.<ext>` | `misc_doc_ISP3000_0ec987.pdf` |
| `label` | **原始目录路径（完整中文）** | `稳定版/5.2.2/5.2.2.22550` |
| zip 内条目 | 原始文件名（中文完整保留） | 解压即得原文件 |

> **打包采用 store（不压缩）**：固件多为已压缩或加密格式，实测 deflate 仅省 0.8%、LZMA 反而增大约 0.5%，
> 压缩无收益且大幅拖慢速度。

## 七、如何还原

1. 下载所需版本的 zip（如 `stable__5.2.2__5.2.2.22550.zip`）；
2. 解压 → 包内为**原始文件名**，直接得到固件本体；
3. 用 `MANIFEST.csv` 的 MD5 逐个校验完整性。

**`MANIFEST.csv` 字段**：`release, asset_name, label, size, download_url`（共 361 行）

**整库还原**：`git clone` 后配合 `gh release download` 批量拉取，或用 IDM 导入资产直链。
