## 一、如何找固件

1. **确认型号**：在 [MODEL_INDEX.md](MODEL_INDEX.md) 里按型号查「最新版本 / 全部版本 / 下载包」；
2. **选择版本**：到 Releases 选择对应分类（稳定版 / 公测版 / 底包 / AP 等）；
3. **下载解压**：下载对应版本的 zip，解压后按 `GOCLOUD-<型号>-<版本>` 取文件。

> Releases 中的 zip 按版本命名（如 `stable__5.2.2__5.2.2.22550.zip`），更多历史版本可在 Releases 列表中按版本号查找。
> 只知道型号、不知道版本？可先在 [MODEL_INDEX.md](MODEL_INDEX.md) 里查该型号的「最新版本」，或到官方帮助中心核对。
> 跨大版本升级、或从第三方固件切换时，建议先刷「底包」再刷目标版本。

## 三、文件格式与刷机

| 后缀 | 用途 |
|---|---|
| `.bin.web` | MTK 机型升级包（网页后台上传） |
| `.bin.online` | 部分 RE 机型升级包 |
| `.iso` / `.img` / `.GHO` | x86 机型安装镜像 / 写盘镜像 |
| `.rar` / `.zip` | 底包、二合一安装包等 |
| `.ini` | 厂商发布清单 |

- x86 机型（SX / ISP 系列）用 `.iso` / `.img` 装机；
- MTK 机型（S1A / S2A / S3A 等）用 `.bin.web` 升级包；
- 跨大版本或从第三方固件切换时，先刷「底包」再刷目标版本。
